# Google Sheets Score Comparison
**Purpose:**
This project connects to multiple Google Sheets and calculates and compares final scores between them.

**Technologies Used:**
__gspread__ Utilized to interface with the Google Sheets API for reading and extracting data from cells.
__google.auth__ Utilized for authenticating Google Drive in order to be able to retrieve infromation from the Drive.

**How to Use:**
This code works best in a Google Colab file within your Google Drive.
The URL's of the Google Sheets need to be used in order to connect to them for this project.
